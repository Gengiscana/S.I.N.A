# S.I.N.A ⇩
Projeto S.I.N.A (Sistema Integrado de Aprendizagem Ativa)

O Que é o Projeto:  
Um Sistema composto por uma câmera com scanner sobre um tripé e conectado a um Site que utilizaria um sistema parecido com o do Plickers (Escaneia cartões com QR codes para ler as respostas de cada aluno).
